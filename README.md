# 🌍 Travel Booking Platform

A full-stack travel booking platform that allows users to explore destinations, view detailed travel information, and book trips seamlessly. The platform provides a smooth and responsive user experience for travelers while offering management features for administrators.

## 📖 Project Overview

The Travel Booking Platform is designed to simplify the travel planning process by allowing users to browse destinations, view travel packages, and make bookings online. The application features secure authentication, responsive design, and a user-friendly interface to ensure a seamless experience across all devices.

---

## ✨ Key Features

### 🏝️ Destination Exploration
- Browse popular travel destinations.
- View detailed information about each destination.
- Search and filter destinations efficiently.

### 📅 Online Booking System
- Book travel packages directly through the platform.
- Manage booking information easily.
- View booking history and status.

### 🔐 Authentication & Authorization
- Secure user registration and login.
- Protected routes for authenticated users.
- Role-based access control for users and administrators.

### 📱 Responsive Design
- Fully responsive across desktop, tablet, and mobile devices.
- Modern and intuitive user interface.

### ⚡ Dynamic Data Management
- Real-time data fetching.
- Efficient state management.
- CRUD operations for travel destinations and bookings.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/travel-booking-platform.git
```

### Navigate to Project Directory

```bash
cd travel-booking-platform
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=your_api_url
MONGODB_URI=your_mongodb_uri
BETTER_AUTH_SECRET=your_secret
BETTER_AUTH_URL=http://localhost:3000
```

### Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
